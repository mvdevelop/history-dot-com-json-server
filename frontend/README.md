# History.com - Frontend

This directory contains the React frontend application for History.com.

## Contents

- `src/` - React application source code
- TypeScript configuration
- Build artifacts

## TypeScript

This project uses TypeScript for type safety and better developer experience.

## Dependencies

- React with TypeScript
- Vite for build tooling
- Bootstrap 5 for styling
- React Router for navigation

## Scripts

```bash
# Development
npm run dev

# Build
npm run build

# Preview
npm run preview
```

## Backend API

This frontend connects to the backend API at:
- `http://localhost:3001`
- API endpoints: `/api/content`, `/api/users`

## Navigation

The application features:
- **Home** - Content listing
- **Content** - All historical content
- **Contact** - Contact page (placeholder)
- **Extra** - Extra content (placeholder)
- **Add Content** - Form to add new historical content

## Technologies

- React 19 with TypeScript
- Vite 7
- React Router
- Bootstrap 5
- Tailwind CSS
- JSON Server (for development)
